Other devices

Android phone or tablet

Download LightMoon.apk

  1. Open the downloaded file (tap the download notification, or find it in Files → Downloads).
  2. If Android asks, allow your browser to install unknown apps, then go back and tap Install.
  3. If Play Protect warns about an unknown app, tap More details → Install anyway. LightMoon isn't on the Play Store, so Android always asks.
  4. Open LightMoon. Installing a newer APK later updates it and keeps your data.

The Android app can do the most: the wake phrase ("Hey LightMoon"), calls, messages, notifications and the quick panel.

iPhone or iPad
  1. Open this page in Safari.
  2. Tap the Share button (the square with an arrow).
  3. Scroll down and tap Add to Home Screen, then Add.
  4. Open LightMoon from the new icon on your Home Screen.

On iPhone, LightMoon talks, listens when you tap it, and keeps your tasks and reminders. Apple doesn't let it hear a wake phrase or read your messages and calls.

Windows, Mac, Linux or Chromebook
  1. Open this page in Chrome or Edge.
  2. Click Install at the top of this page, or the install icon at the right end of the address bar.
  3. In Edge you can also use ⋯ → Apps → Install this site as an app.
  4. LightMoon opens in its own window and gets a Start menu, Dock or desktop icon.

On a Mac with Safari: File → Add to Dock. Firefox can't install apps; LightMoon still works in a Firefox tab.
